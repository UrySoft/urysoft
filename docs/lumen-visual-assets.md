# Recursos visuales de Lumen

## Icono

`assets/apps/lumen/icon-android-official.svg` es una transcripción determinista del drawable Android `res/drawable/ic_lumen.xml`, comprobado dentro del APK oficial Lumen 4.0.2. Conserva viewport, trazados y colores #101b24 / #91e5cf. No es un rediseño generado. Sustituye en la ficha y en el catálogo a la variante web blanca.

## Capturas actuales

Los PNG `screen-send-4-0-2`, `screen-phrases-4-0-2` y `screen-options-4-0-2` se capturaron a 412 × 915 píxeles CSS en un navegador ejecutando sin cambios los archivos `assets/www` extraídos del instalador oficial publicado. No son capturas de Android emulado ni pruebas de cámara o flash físicos. La ficha identifica su procedencia como interfaz web incluida en el instalador. El mensaje escrito para la imagen es una demostración; no se emitió.

La rama de captura `lumen-capture-4-0-2` conserva los recursos web extraídos para hacer reproducible la sesión. No contiene firmas, claves ni fuentes Android privadas.
